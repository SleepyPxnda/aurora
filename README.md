# aurora

Architektur-Reviews nach [LASR](https://www.lasr-reviews.org/de/), gemeinsam im Browser und in Echtzeit. Ein Team geht mit einer Moderation durch Mission Statement, Bewertungsmaßstab, Basis-Review und zielorientierte Analyse und erhält am Ende einen Bericht als Markdown oder AsciiDoc.

## Run

Requires Node 22+ and pnpm.

```sh
pnpm install
pnpm dev        # http://localhost:3000
pnpm test
pnpm typecheck
pnpm build
```
